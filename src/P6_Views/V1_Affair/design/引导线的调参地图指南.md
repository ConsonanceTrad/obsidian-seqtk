# A. 线的形状与几何 —— 全部集中在 design/guides.ts
`renderTreeGuides()` 里只有两个坐标量 + 两类线段决定线长什么样：
```TS
65:  const step = opts.step ?? 18;              // 单级缩进步距
66:  const base = opts.base ?? 8;               // 内容列基准
103: const parentX = parentLeft + base + (depth - 1) * step;  // 竖线所在的列
104: const contentX = rowLeft + base + depth * step;           // 横线终点
105: const centerY = r.top - oy + r.height / 2;                // 本行中心
106: const parentCenterY = p.top - oy + p.height / 2;          // 父行中心
107: const bottomY = r.top - oy + r.height;                    // 本行底部
111: d.push(`M ${parentX} ${parentCenterY} V ${isLast ? centerY : bottomY}`);  // 竖笔
113: d.push(`M ${parentX} ${centerY} H ${contentX}`);                          // 横笔
```
想要的视觉效果	改哪里
竖线的横向位置（列对齐）	`parentX`（103）
横线终点离徽章的距离	`contentX`（104）。现在正好落在内容列起点＝徽章左缘；想留空隙改成 `... + depth * step - 3`
横线不在行正中（略偏上/下）	`centerY`（105）的 `r.height / 2`，例如 `* 0.42` 或 `- 1`
竖线不要穿过父行（只从父行底部起）	`parentCenterY`（106）→ 改成 p`.top - oy + p.height`
末子 └ 收尾的高低	`isLast ? centerY : bottomY`（111），例如 `centerY` 换成 `centerY - 2`
行与行之间的线断开一截	`bottomY`（107）→ `+ 1` 或 `+ 2`（补上行 `margin: 2px 0` 的间隙）
只在末子画线、其它不画	在 105-113 之间按 `isLast` 早退

# E. ⚠️ 如果要改 step（比如 14 → 16），必须同步 7 处
漏掉任何一处都会「线与内容错位」或「一动就跳位」：

位置	内容
Design.ts:349	左栏行缩进 `8 + depth * 14`
Design.ts:613	右栏行缩进 `8 + depth * 18`
Design.ts:351 / 615	`--seqtk-parent-x`（折叠方块）
Design.ts:322	左栏 `renderTreeGuides(..., { step: 14 })`
Design.ts:538 和 567	右栏 `renderTreeGuides(..., { step: 18 })` —— 两处（`renderRight` 与 `renderAllOverview`）
Design.ts:270 / 271	`observeTreeGuides(..., { step })` —— 最容易漏，它负责尺寸/滚动后的重绘，漏了就会「一动就跳位」
NodeTree.svelte:21 + Design.ts:592 的 step: 18	Svelte 树
如果你打算调步距，我建议顺手把这个常量收敛到 guides.ts 导出（例如 `export const TREE_STEP = { left: 14, right: 18 }`），上面 7 处改成引用就不会漏。
